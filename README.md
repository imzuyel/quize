## দ্রুত শুরু

```bash
npm install
cp .env.example .env          # DATABASE_URL বসান
npx drizzle-kit push          # টেবিল তৈরি
npm run dev
```

ডেমো মোডে হোমপেজ থেকে যেকোনো ভূমিকায় এক ক্লিকে প্রবেশ করা যায়।

## লাইভে দেওয়ার আগে

```bash
DEMO_MODE=false                                    # ⚠️ আবশ্যক
npx tsx scripts/setup-production.ts admin@school.edu 'StrongPass'
npm run build && npm run start
```

বিস্তারিত ধাপ **[DEPLOY.md](./DEPLOY.md)** এ।

## এআই কী

কী ছাড়াও সব ফিচার চলে (বিল্ট-ইন জেনারেটর)। মান বাড়াতে একটি ফ্রি কী দিন:

- **Google Gemini** ⭐ — [aistudio.google.com/apikey](https://aistudio.google.com/apikey) — স্থায়ী ফ্রি, কার্ড লাগে না
- **Groq** — [console.groq.com](https://console.groq.com/keys) — ফ্রি টিয়ার

কী বসানোর দুটি উপায়: `.env` ফাইলে, অথবা **অ্যাডমিন → 🔑 এআই কী** পেজে
(সেখানে যাচাইও করা যায়)। একাধিক কী দিলে একটি ব্যর্থ হলে পরেরটি স্বয়ংক্রিয়ভাবে
ব্যবহার হয়।

## সীমাবদ্ধতা

- **লাইভ কুইজ** এক-ইনস্ট্যান্স সার্ভারে চলে (~৫০০-১০০০ জন)। Vercel-এর মতো
  মাল্টি-ইনস্ট্যান্স হোস্টিংয়ে লাইভ মাল্টিপ্লেয়ারের জন্য Redis অ্যাডাপ্টার লাগবে।
- **স্ক্যান করা PDF** থেকে টেক্সট পড়া যায় না (OCR নেই)।
- **PPTX-এ** অ্যানিমেশন ও ভিডিও যায় না — ব্রাউজারের উপস্থাপন মোডে সব দেখা যাবে।
